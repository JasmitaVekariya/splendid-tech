# Splendid Tech IT Solutions Redesign Context

## 🎯 Requirements
* **Framework:** Next.js (latest version 16.2.4 with App Router)
* **Design Style:** Clean, modern, "classic premium" look. Smooth animations and micro-interactions. Highly responsive (mobile-first).

## 🎨 Branding & Theme (VERY IMPORTANT)
* Strictly follow the color palette from the company logo.
* **Colors extracted from Logo:**
  * **Primary:** Vivid Blue
  * **Accents:** Cyan, Yellow, Magenta (from the stylized 'E' and subheading).
* Maintain consistent color usage across all sections (buttons, backgrounds, text, hover states).
* Ensure the design feels cohesive, branded, and visually aligned. No unrelated colors.

## ✨ Animations
* Smooth, subtle premium animations using Framer Motion or GSAP.
* Includes: Scroll-based animations, Hover effects, Page transitions.

## 🧠 UI/UX Improvements
* Improve layout clarity and readability.
* **Sections:** Hero, Services, About, Testimonials, Contact.
* Use modern UI patterns (cards, grids, CTA sections).

## ⚡ Performance
* Optimize for fast loading.
* Use image optimization and lazy loading.
* Follow SEO best practices.

## 🛠️ Required Skills & Tools
* **Frontend:** Next.js (App Router, SSR, SSG), React.js (Hooks, Component Architecture)
* **Styling:** Tailwind CSS (v4 is installed)
* **Animation:** Framer Motion / GSAP
* **Other:** Modern web design trends, UI/UX principles.
